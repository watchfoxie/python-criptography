# python-criptography

![python-criptography logo](public/python_criptography.svg)

## Descrierea proiectului

python-criptography este o colecție de implementări didactice dezvoltate în limbajul de programare Python, destinată studiului algoritmilor fundamentali de Criptografie clasică și modernă: cifruri de substituție, cifruri de bloc simetrice, criptosisteme asimetrice cu cheie publică, scheme de semnătură digitală și funcții de dispersie (hash). Materialul este structurat pe șase laboratoare tematice, fiecare organizat (lab-1 până la lab-6), iar interfața fiecărui program este de tip linie de comandă (CLI), interactivă sau parametrizată prin argumente (modulul standard argparse).

Structură:

1. Laboratorul 1 (lab-1) tratează cifrul lui Cezar.
2. Laboratorul 2 (lab-2) abordează criptanaliza cifrurilor monoalfabetice prin analiza frecvenței literelor în limba engleză și în limba română.
3. Laboratorul 3 (lab-3) implementează cifrul polialfabetic Vigenère, adaptat alfabetului român de 31 de caractere (A-Z plus diacriticele Ă, Â, Î, Ș, Ț).
4. Laboratorul 4 (lab-4) tratează algoritmul standard de cifrare în bloc, DES.
5. Laboratoarele 5 și 6 abordează criptosistemele asimetrice cu cheie publică.
